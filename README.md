# MedVerse
A responsive medical learning portal built with React, Vite and Supabase. Features authentication, student dashboard, published tests/MCQs, study materials, OSPE practice, Pearl Points and profile.

## Deploy
Set VITE_SUPABASE_URL and VITE_SUPABASE_ANON_KEY in the hosting environment, then run npm run build and serve the dist folder on port 8080.
